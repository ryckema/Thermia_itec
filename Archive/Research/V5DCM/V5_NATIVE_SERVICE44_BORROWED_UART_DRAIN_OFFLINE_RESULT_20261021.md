## Conclusions, hypotheses, unknowns
**PROVEN (source-level):** the old V5 ESPHome adapter does not propagate write/drain completion errors, so its `GuardedPort` success predicate cannot substantiate safe physical release. This blocks source promotion into a new embedded TX target until corrected. Inherited S43 still completely DENIES embedded TX.

**STRONGLY SUPPORTED:** a distinct, single UART owner with explicit admission/drain/error/DE-signal provenance is needed; the exact 2026.9.0 ESPHome installation has an unbuffered UART TX path. **The S44 eight-poll host drain is synthetic test geometry, NOT a measured XTR deadline.**

**OPEN / UNKNOWN:** exact physical shifter/stopbit completion, adapter's intended embedded UART port identity, DE safety under abort while bytes remain in flight, actual current responder/slot/epoch, B11D first-fault cause, actual TX-aware callback scheduling, original Thermia Connect C2, semantic write/readback. **An error path forcing DE LOW while bytes are still in flight may truncate a frame, so safety requires hardware validation.** Historic local V4.1 successes and prior G01–G06 installation-scoped user-accepted experimental risks stand, but neither proves physical electrical exclusivity.
