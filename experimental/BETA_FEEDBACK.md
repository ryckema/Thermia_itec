# CM930 Universal Beta Feedback

This firmware needs to be tested on different heat pump models and controller firmware versions. Your feedback will help us improve compatibility and identify model-specific differences.

If you encounter any issues, please consult the [README](README.md) in this directory before submitting your feedback.

## Please provide the following information:

- **Heat pump model and controller firmware version** (as displayed on the control panel, e.g. iTec XTR M, 2.4.2).
- **Passive readout:** Does passive data readout work? Are the sensor values correct?
- **DCM session:** Does the native DCM session start successfully and automatically?
- **Calendar:** Can you read the calendar entries? This helps confirm that the native DCM session and configuration synchronization are working.
- **Write functionality:** Can you change supported settings through Home Assistant? Are the changes reflected on the heat pump's control panel?
- **Other issues:** Have you encountered any missing or incorrect values, connection problems, unexpected behaviour or other issues?

Please report both successful and unsuccessful results. Feedback from different models and firmware versions is particularly valuable.

**Please post your feedback in the [GitHub Discussions](https://github.com/ryckema/Thermia_itec/discussions).**
