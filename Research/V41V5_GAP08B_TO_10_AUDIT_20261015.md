## GAP-10 — COMPLETE / NEGATIVE (offline revocation-policy hypothesis disproved)
- **Hypothesis:** transient loss of runtime/mailbox and loss of trusted owner input must not allow stale cached `write_base` to become authoritative on simple toggle back.
- **Baseline:** GAP-09 host source comparison and GAP-07 fresh/retained/recovery invalidation; bundled GAP-08 portable core, no hardware TX.
- **Controlled change:** *none* to production/source deployed on ESP; offline isolated C++ host harness only. Ran 23/23 assertions/checks; successful execution is not a positive result for the tested safety invariant.
- **Host-observed NEGATIVE:** `set_mailbox(false)` and `set_runtime_normal(false)` immediately block `write_ready`, but alone do not revoke historical page `write_base`. Restoring the boolean can re-expose old authority without receiving a new qualified page. In contrast, `begin_fresh`, `begin_retained`, `begin_recovery` revoke cached write authority while keeping diagnostic bytes.
- **Separate defensive API concern:** synthetic inconsistent `Decision` with owner label but `authorized=false` can be given to `commit_fc16()`, which accepts owner-label-derived authority. Normal `fc16_decision()` path has not been shown to produce this mismatch. This is a trust-boundary concern, **not proven live exploit or local physical write**.
- **Strong conclusion:** revocation policy is insufficient as a standalone precondition for any future native TX. Current deployed RX-only `HARD_DENY` remains unaffected; no native bus TX was performed.
- **Next, GAP-11 PREPARED / NOT RUN:** offline fail-closed revocation policy design and host regression, explicitly separating harmless temporary functional disable from provenance/owner/epoch invalidation. Requalification must require newly observed qualified page provenance, not toggling stale flags. Test both cache and effective authority, including synthetic contradictory decision fields. Preserve all live V5 RX-only production behavior. No OTA or physical TX.
- **Abort:** any patch broadening write authority, weakening deny or modifying production UART handling; recovery preserve current GAP-08 firmware.
- **Open:** autonomous controller epoch, owner, physical wire EOF, response slot, electrical DE and reset/brownout fail-low (G01–G06); exact raw bus parity of complete native session.
